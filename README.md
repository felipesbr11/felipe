O objetivo deste trabalho foi investigar como técnicas de Machine Learning podem
auxiliar na análise da qualidade de vinhos. Para isso, foi utilizado o conjunto de dados
Wine Quality – Red Wine, disponibilizado pela UCI Machine Learning Repository.
A base contém informações físico-químicas de vinhos tintos, incluindo variáveis como
acidez fixa, acidez volátil, ácido cítrico, açúcar residual, cloretos, dióxido de enxofre,
densidade, pH, sulfatos e teor alcoólico. A variável quality representa uma nota de
qualidade atribuída aos vinhos.
Neste projeto, a variável quality foi transformada em duas classes: “Qualidade
baixa”, para notas menores que 6, e “Qualidade alta”, para notas iguais ou maiores
que 6. A partir disso, foram realizados experimentos de classificação supervisionada e
agrupamento não supervisionado.
